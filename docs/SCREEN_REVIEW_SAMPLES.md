# 画面確認用サンプル

設定 → 診断とプレビュー → **画面確認用のサンプルを追加**。
既存の記録・下書き・進行中のAsk AI会話を置き換えず、SQLiteへ一括追加する。
固定IDを使い、繰り返し追加しても既存サンプルの編集を上書きしない。

- ライブラリ：文字起こし前、要約前、取り込み中、文字起こし中、要約中、要約済み、文字起こし失敗、要約失敗の8件。
- 各記録：要約・文字起こし・ノートの実画面。音声ファイルは含まない。
- プロジェクト：「画面確認（サンプル）」に8件を所属させる。
- ジャーナル：状態別の記録へ移動できる8件。
- タスク：未完了・完了の2件。通知は予約しない。
- 資料：Markdown資料と2枚のスライド。
- 人物：田中（サンプル）。
- Ask AI：Memoraメニュー → 履歴に架空の会話を1件。現在の会話や下書きは変更しない。

処理中のサンプルは表示状態を固定し、ProcessingServiceのジョブを作らない。
録音・音声生成・文字起こし・AI送信・連携サービス・通知は実行しない。
マーケットプレイスは既存カタログを使用し、公開数や接続状態のサンプルは捏造しない。

サンプル削除バナーから、関連するサンプルの記録・ジャーナル・タスク・人物・資料・質問履歴を削除できる。
サンプルプロジェクトや人物を本人の記録が参照している場合は残す。
