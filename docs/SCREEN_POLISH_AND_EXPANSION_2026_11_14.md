# 全画面の磨き込み・スキル・コネクター拡張

## 承認済みの範囲

共通の余白と情報階層、接続状態の意味、主要操作の分かりやすさを整える。
仕事向けのGitHub・Linearを既存MCPで追加し、学習・文章・創作・暮らしの
16スキルを加える。Notion検索、Drive、Slackの認証基盤は次段階。

## 実装単位

1. 共通余白・人物の表現・回答の共通表示・接続要件の表示。
2. 記録／資料／文字起こし／編集／復旧の操作と状態。
3. 用途別カタログと16スキル、既存業務スキルの手順を改善。
4. GitHub・Linear、MCPの対象選択と読み込み上限の明示。

## 保持する動作

SQLiteとメディア原本、下書き、スキル／ナビゲーションの既存IDを保持する。
詳細とAsk AIには作成FABを表示しない。文字入力と添付ホストを維持する。
表示だけで外部呼び出し・書き込み・承認を実行しない。
共有の閲覧専用、記録の送信許可、MCPの接続先・認証・料金確認を維持する。

## 検証の記録

実装単位ごとのビルド、ホスト検査、E2Eと画面確認の結果を追記する。
実機・実アカウントによる確認と、ローカルの固定fixtureを分ける。

### GitHub・LinearとMCP

- 公式の読み取り専用エンドポイントに固定した手動トークン設定を追加。
  GitHubはIssues／Pull requests、LinearはIssue／プロジェクトを対象とする。
  [GitHub公式仕様](https://github.com/github/github-mcp-server/blob/main/docs/remote-server.md)、
  [Linear公式仕様](https://linear.app/docs/mcp)を参照。
- 接続先UUIDへの明示指定を解決し、4件超は送信前に拒否する。自動選択は
  接続名と確認済みのキャッシュを端末内で検索し、登録順の先頭4件に依存しない。
- 40ツール／4ページの一覧上限、回答ごとの16ツール／外部JSON Schema 24KiB制限を維持。
  一覧を一部しか読めなかった場合は全件と誤認させない表示を追加。
- プリセットは書き込みツールを読み込み・実行の両方で拒否する。
  GitHub専用ヘッダーは公式の固定URL・固定値だけ許可する。
  最初の通信テストでヘッダー拒否を検出し、限定的な許可後に再検査が成功。
- MCP本番オーケストレーションのモック検査、63競合状態、23失効条件、
  6件目の選択、4件超の拒否、誤URL、OFF→ON時の失効、書き込み拒否が成功。
  HTTPフレーミング・固定ヘッダー・OAuth・プラグイン権限の検査も成功。
- iOSプレビュー成功（既存警告11件）。GitHub／Linearの設定E2Eは
  ライト／ダークで成功。空トークンで保存・接続できないことを確認。
  実トークンは入力せず、実サービスへの認証・取得成功は未検証。
- スキルの新メタデータを含む実ファイルのバックアップ往復と、
  サーバー側の任意メタデータ・上限拒否テスト8件も成功。
