# 主要画面と共通UIの見直し — 2026-11-13

ユーザーの白基調・余白のある参照デザインに合わせ、既存の情報構造を保って
読みやすさと操作領域を見直した。

## 確認範囲と修正

| 画面・共通部品 | 見直した点 |
| --- | --- |
| ライブラリ | 拡大文字でアイコンが縦配置になる際、バッジ・プレビューもタイトルと左端を揃える。選択マークの置換と非アニメーションは維持。 |
| プロジェクト | 長い名前や補足の中央に操作メニューが浮かないよう上揃え。拡大時はアイコンを上へ移し本文幅を確保。 |
| 参考資料 | 拡大時のタイトル2行制限を解除。サムネイルを上へ移し、原文種別・日時・失敗表示の幅を確保。 |
| ジャーナル | タイムラインの追加ピルを固定44pt高から可変高に変更。大きな文字も収め、既存の追加メニューを維持。 |
| Ask AI・記録詳細 | 長い対象名で質問欄が埋まらないよう短いプロンプトに変更。実際の対象名は読み上げヒントへ残す。質問対象・下書き・送信経路は変更しない。 |
| マーケットプレイス | 拡大時はアイコンをテキストの上へ置き、追加・操作ボタンを上揃え。「利用中」の件数タイルを可変幅・高さにし、省略記号になる問題を修正。 |
| 資料一覧 | タイトル→日時等の補足→本文プレビューに統一。通常時はアイコン上揃え、拡大時は縦配置。 |
| 人物一覧・詳細 | 名前・メモを折り返し、拡大時はアバターを上へ移して本文幅を確保。「佐藤さん」等の名前にさらに「さん」を付けない質問ボタンにし、読み上げでは対象名を保持。 |
| 検索 | 拡大時は見えるプレースホルダーを「検索」に短縮。アクセシビリティ上の検索範囲・フォーカス・解除動作は維持。 |
| サンプル表示 | 補助表示と削除ボタンを短くして本文を優先。削除確認と本人の記録を保護する処理は維持。 |
| 設定・マーケットプレイス詳細 | 既存のネイティブの値表示・縦配置・フォームが大きな文字に対応していることを確認し、構成は維持。 |

サイドメニューの4つの入口、ファイル詳細・Ask AIのFAB非表示、下部の共有カプセル、
編集時の下書き保護、引用リンク、ストリームの末尾フェードを保持する。
