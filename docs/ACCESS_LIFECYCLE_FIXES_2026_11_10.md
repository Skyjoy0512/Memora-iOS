# 編集・外部送信の状態変更への対応 — 2026-11-10

## 個人データの編集制限

タスクの完了・日付・削除・挿入・復元、資料の追加・更新・削除、プロジェクトの
追加・名前変更・削除・ファイル移動、音声の削除、会議／日記のゴミ箱操作・期限整理、
Undoに、復元中・チーム選択中・保存保護中の拒否を追加した。
自動位置記録の受信箱も、その間は取り込まず保持する。

検証: `run-person-task-checks.sh`、`run-artifact-provenance-checks.sh`、
`run-recording-media-checks.py`成功。本番メソッドと実SQLiteを使い、各状態で
メモリと保存済みのバイトが変わらず、写真・音声が削除されないこと、Undoが
消費されないこと、個人モードへ戻ると編集できることを検査した。
プロジェクトの関連資料／チャットと通知・検索サービスはfixture。
