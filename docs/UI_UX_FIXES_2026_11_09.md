# UI/UXレビューの修正 — 2026-11-09

状態: 実装済み。ホスト検証とiOSビルドを実施。実画面・実機・今回のE2Eは未検証。

## 対応した追加指摘14項目

1. AI質問は選択だけでは進まず、次へ／送信で確定。自由入力の途中送信を除去。
2. ノート添付は64件超過を全体拒否。既存のリンクを部分更新しない。
   選べる残数と選択数を表示し、上限でも選択解除は可能。
3. 回答の表・グラフ・時系列・補足をコピー／共有／資料保存へ含める。
   タスク・予定等は実行時の参照許可と実データを使用。JSONから権限や値を復活させない。
4. インライン／ブロック編集に保存中・未保存・再試行を追加。失敗時は入力と下書きを保持。
5. 録音保存中の一時停止・破棄を無効化。録音メモに読み上げ用ラベルを付与。
6. 変更できないプライバシー設定は閲覧のみと明示し、区分の操作も無効化。
7. ライブ文字起こしは既存のConversationScrollStateで手動閲覧を尊重。
   新しい発言は「最新へ戻る」で追従を再開できる。
8. マーク追加でメモ画面から移動しない。件数、触覚、アクセシビリティ通知で結果を示す。
9. キーボードを閉じたら、表示前の録音シートの高さへ戻す。
10. 資料・ノート添付、元の会議の選択に検索を追加。
11. プロジェクトの絞り込み条件と解除操作を常時表示。
12. AI質問の操作領域を44ptへ統一し、大きな文字ではフッターを縦配置。
13. 回答から保存した資料のsourceAnswerIDを保持し、再度の保存操作は既存資料を開く。
    フィールドは任意で、旧資料・旧バックアップの復号を維持。
14. ゴミ箱の完全削除確認に対象名を表示。

## 先のUIレビューへの追加対応

- AI設定は実際の選択モデル・処理先・利用可否を表示。登録モデルの優先を説明。
- 古い「AI整理」設定名を現在の経路へ修正し、回答からAIモデル設定へ移動可能にした。
- 一覧は取り込み中／文字起こし中／要約中を区別。作成・再試行の操作名を整理。
- 資料・人物はコレクションのルートだけサイドメニューを使用できる。
  さらに深い詳細の戻る操作と、保存済みのルート識別子は維持。
- ファイル／プロジェクトの操作メニューに検索入口を追加。
  メニューの検索対象も現在の資料／人物／ファイル／プロジェクトに合わせる。
- 一覧の日時・長さ・状態はアクセシビリティ文字サイズで縦配置。
- ネストした回答のタスク参照も表示時に検証。
- 書き出した表のエスケープされた縦線を、別の列と誤認しないようパーサーを修正。
- DESIGN.mdの旧メモ専用ボタンの記述を現在の共有＋メニューへ揃えた。

## 検証

- `bitrig build -destination 'generic/platform=iOS Simulator'`: 各変更単位で成功。
- `run-ui-interaction-checks.py`: 質問の未送信、自由入力、保存失敗／再試行、構造化出力、
  参照拒否、添付上限。質問と保存の本番メソッドを抽出し、UIと保存先の境界はfixture。
- `run-project-source-storage-checks.sh`: 実SQLiteで63→65件を拒否し、63→64件を許可、
  満杯時の追加も拒否。拒否前後の再読み込みで変更がないことを確認。
- `run-inline-citation-checks.sh`: 回答保存の出典とsourceAnswerIDの往復、旧形式の復号。
- `run-artifact-provenance-checks.sh`: 実際の参照許可に従うタスク書き出し、
  許可失効・ワークスペース変更後の拒否。provider／dispatchはmock。
- `run-design-refresh-checks.sh`: 設定、アイコン、チャット、候補、待機表示、文字組み等。
- `run-optimization-checks.py`: 既存の検索・保存・ナビゲーション・権限の回帰。
- `run-editor-recovery-checks.py`: 下書き互換と復旧、週報保存。
- `run-motion-loading-checks.sh`: 手動スクロール、読み込み、Markdown解析、Reduce Motion。
