# 画面右上の操作

- 通常の操作は `ToolbarActionItem` に置く。追加・新しいチャット・その他は右端に置き、その左に検索・共有・絞り込みを置く。
- iOS 26以降は44ptの丸いLiquid Glassを個別に表示する。ボタンは共通背景を隠して44ptの枠を描く。メニュー・ピッカーは `usesSystemBackground: true` と36ptのラベルで標準の44pt外形を使い、2つ続く場合は `ToolbarActionGap` で分ける。メニューに独自ガラスを重ねると枠が消えるため、標準背景を使う。iOS 26未満はシステム標準のツールバーを使う。
- ボタンには `ToolbarIconButton`、メニュー・ピッカーのラベルには `ToolbarActionLabel` を使う。検索の図柄は26pt、それ以外は20ptを基準としてDynamic Typeに追従し、枠からはみ出さないよう最大32ptにする。
- 検索操作は `ToolbarIconGlyph` が `search-intelligence` に解決する。検索入力欄も同じアートワークを使う。
- Ask AIの独自ヘッダーも44ptの丸いボタン、12ptの間隔、20ptの左右余白に揃える。タイトルや会話の配置は変えない。
- ファイルから詳細への検索→共有と並べ替え→その他、および再生の分割モーフィングは幅・ガラスIDを維持する。この2画面には追加のスペーサーを入れない。
- 設定のフォーム、編集のキーボードツールバー、完了・キャンセルの文字ボタンは対象外。操作の意味や機能は変えない。
