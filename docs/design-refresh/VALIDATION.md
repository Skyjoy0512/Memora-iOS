## iOS E2Eの実行方法

Bitrigのプレビューとは別のXcode Simulator（iPhone 18 Pro Max、iOS 27.0）に、
Bitrigがビルドした実際のMemora.appをインストールして操作する。
`launchMemora`はシナリオごとに**このテスト端末のMemoraだけ**を再インストールし、
通常の「スキップ」操作で初回案内を完了する。プレビュー端末のレコード・設定は初期化しない。
保存テストのシナリオ内再起動では再インストールせず、同じSQLiteの再読込を検証する。

全テストは決定的なUI操作とローカルfixtureを使用し、agent/model APIを呼ばない。
既存のURLソース取込テストだけは`example.com`をHTTPで読むためネットワーク接続が必要。
e2e.config.tsのモデル指定は既存設定であり、これらのテストにプロバイダーキーは不要。
実行中の成果物・失敗トレースは`.e2e/design-refresh/`、`.e2e/regression/`に出力され、
Gitには含めない。代表画像だけを`after/`へ保存する。

```sh
npx e2e run --output .e2e/regression --max-duration 1200000
# OSの文字サイズをAccessibility XXXLに設定したテスト端末で別途実行し、終了後Largeに戻す
npx e2e run tests/design-accessibility.e2e.ts --output .e2e/accessibility --max-duration 300000
```

## 回帰で検出・修正した点

初回の全体E2Eは19/27通過。候補の閉じるボタンが見た目上44ptでも、実際の
アクセシビリティ枠は小さいことを検出し、Buttonのラベル自身に44ptを持たせた。
新しいE2EではAX枠の幅・高さを実測する。
ネイティブタブの移動中タップ、自動フォーカスとの競合、スクロール、戻る／送信の
曖昧なテストロケータも修正した。失敗ケースのskipや検証条件の削除では解決していない。
追加した検索ケースも含め、アプリのコードを固定して全28件を実行した。
結果は**27/28通過**（実行ID：`01a1566a-c032-764f-bd47-c8e3065cd4d5`、612.22秒）。
失敗は既存の「資料・進捗の表示確認」をタップした後も検証メニューに留まった1件。
遷移／スクロール中の位置競合を避けるため、Buttonの実枠が安定したことを待ち、静的なテキストではなく
名前付きButtonを操作するようにテストを補正した。アプリの処理や保存形式は変更していない。

補正後、既存`tests/memora.e2e.ts`の**10/10件が通過**（実行ID：
`01a15674-f9f3-712e-9cfd-ce850c1cfa59`、138.23秒）。
失敗した資料・進捗表示を含み、初回案内の保持・タブ・設定・作成・タスク・回答表示も再確認した。
全体実行と再実行を合わせて**異なる28ケースすべての通過**を確認。
これは単一の全体ランが28/28だったという意味ではない。
ケース別の結果と実行IDは[RESULTS.json](RESULTS.json)に保存した。

## 検証の境界・残課題

- グローバルの@選択・複数指定・削除・＋からの呼び出しと、プロジェクト内の選択はUI E2Eの対象。
  registryでの実行・権限拒否・取り消しはホストの実コード＋mock providerで検証。
  認証済みの実プロバイダーを使った@からのクラウド回答／外部サービス実行は今回未検証。
- プロジェクト内は読み取り専用。未対応の外部MCP・書き込みスキルを利用可能とはしない。
  記録単体の@指定は未対応で、残った指定を黙って無視せず理由を示しドラフトを保持する。
  プロジェクト専用ソースを全体のAsk AIへ持ち越した場合も、利用不可表示・送信拒否・ドラフト保持。
- 録音・音声認識エンジン、CloudKit、Gmail OAuth、実決済、実機の権限ダイアログは
  実アカウント／ハードウェアを使った再検証が必要。今回それらのサービスを新規接続していない。
- VoiceOverはAXラベル・選択状態・主要操作を確認。全画面の読み上げ順序の聴取検証は未完了。
- 日本語IMEの未確定文字列・UTF-16範囲保護はホスト検査で確認。
  実機キーボードによる変換・再変換・カーソル操作の組み合わせ網羅は未実施。
- iOS 26はデプロイ対象としてビルド済みだが、今回のE2EランタイムはiOS 27.0。
  iOS 26端末・iPad・折りたたみ端末での操作検証は未実施。
- 主要画面のLight／Darkを画像確認。全設定・全プロバイダー・全失敗状態の画像網羅ではない。
- Bitrig内のAX読取りが再起動後に応答しなくなったため、以後の操作E2Eは別のテスト端末で継続。
  コンパイル成功を、その端末の目視確認や実サービス接続成功に置き換えていない。
- 10月20日再開時にはテスト用ランナーにもviewport読取エラーが発生。
  エラーメッセージに従いランナー停止と**テスト用端末だけ**の再起動で復旧した。
  その後、初回案内の完了設定が通常再起動後も残る独立E2Eが通過した。
