# 設定・メニュー・アイコンの磨き込み — 2026-10-20

設定のトップにカテゴリ、サービス、個別のトグル、宣伝カードが同居していたため、
余白だけでなく情報の階層を変更した。ネイティブUI設計スキルとApple HIGの設定設計に沿い、
トップは「何を設定するか」、次の画面は「具体的にどう設定するか」に役割を分ける。

## 新しい構成

プロフィール編集の下に、4グループ・11カテゴリを配置。
トップには個別のオン／オフ、サービス名、重複したプラン宣伝を置かない。
カテゴリは `SettingsCategory` の型付きルートを使い、実設定は
`SettingsCategoryView` 内で従来のバインディング、確認、保存キーを維持する。

| トップの項目 | 移動した設定・操作 |
|---|---|
| アカウント | サインイン、新規登録、サインアウト、アカウント削除 |
| プランと利用状況 | プラン、AIクレジット、法人ライセンス、チーム共有 |
| 録音と文字起こし | 文字起こし方式・言語・用語集、声のプロフィール、話者識別、外部レコーダー |
| AIと要約 | AIモデル／BYOK、要約スタイル、テンプレート、仕事・活動、スキル、メモリ、常駐エージェント |
| ジャーナル | 移動と滞在、記録しない場所、予定表示、カレンダー選択 |
| 連携 | サービス一覧と認証、MCP接続先、Webhook、ウィジェットとショートカット |
| 表示と操作 | ダークモード、触覚フィードバック |
| プライバシー | Face IDロック、データの保存先の説明 |
| データ管理 | 保存容量、クラウド保管の状態、バックアップ、共有取込、最近削除した項目 |
| ヘルプと情報 | 設定の説明、ヘルプ／規約の準備状態、バージョン |
| 診断とプレビュー | 表示と復旧の検証、DEBUG限定の計測・初期化操作 |

Gmail／Notion／MCPは連携一覧から各サービス詳細を経由して接続設定へ進む。
重複した入口を削除しても認証や接続解除の機能は削除しない。
未接続のアカウント・購入・クラウド等を利用可能とは表示しない。
課金が発生しないローカルプラン選択である旨も残す。

## アイコンと操作領域

設定、サイドメニュー、ワークスペース切替、ツールバー、検索、音声入力の
アイコンを20pt・regularのSF Symbolsに揃えた。メニュー行の配置枠は28pt。
ナビゲーション用だけ既存のoutlineへ解決し、保存済みアイコンの識別子は変更しない。
拡大された検索画像や設定ごとのイラスト、縮尺指定を共通UIから除去した。
写真・プロフィールのアバター、コンテンツの図版、OS自身のメニュー描画は別の役割とする。

設定行はDynamic Typeで折り返し、少なくとも44ptのラベル領域を持つ。
初回のUI検査で、Formの行が高くてもボタンのAX枠が小さいことを検出し、
`SettingsLabel` 自身に最小高さを持たせた。単に外側の余白を増やす修正ではない。

サイドメニューの「プロジェクト／資料／人物」を同じライブラリ節へ統合。
「外部レコーダー」は接続時にも名称を変えず、状態を副文で表示する。
ワークスペース切替の色付きアイコンタイルも共通の中立な配置枠へ置き換える。
最大文字サイズの画像レビューで、上部を固定したままでは説明やプラン名が省略される点も検出。
プロフィールとワークスペースを行と一緒にスクロールできるようにし、説明は折り返す。
フッターだけを下部へ残し、大きい文字のときはプランボタンを「プラン」と表示する。
VoiceOverの名前は「Memora Plus、プランと利用状況」のまま、省略も縮小もしない。
大きい文字では行の接続状態もタイトルの下へ移し、日本語が一文字ずつ縦に折り返されないようにした。
この形状はタイトルの実枠の縦横比を測るE2Eでも回帰確認する。

録音・保存形式・API・権限・料金承認・IME・下部のネイティブタブは変更していない。
旧SettingsPlanCardは削除し、旧アイコン描画の別系統は残さない。
