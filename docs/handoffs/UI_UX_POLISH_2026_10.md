# UI/UXの横断改善 — 2026-10-31

前回の[18項目の改善](UI_UX_IMPLEMENTATION_2026_10.md)とPDF改善に続き、検索・選択・大きな文字・タスク操作・戻る操作を横断して磨き込んだ。デザインは既存のニュートラルな配色・システム文字・Lucideを維持する。サイドメニュー、右上の作成、Ask AIのコンポーザー、承認・予算・参照権限、保存形式、Project.jsonは維持する。

## 確認範囲と今回の対応

| 領域 | 確認した問題・判断 | 今回の対応 |
|---|---|---|
| ライブラリ・プロジェクト・ジャーナルの検索 | 人物/資料/ツールと異なり、入力全体の単純な部分一致。空白だけでも検索済みになる | 共通CollectionSearchへ統一。空白区切りの全語一致、全角/半角・大小文字・濁点アクセントの正規化。空白だけは入力前の案内 |
| 共通の検索欄 | 確定後もキーボードが画面を占める。消去後に入力へ戻りにくい | 検索確定でフォーカスを外し、スクロールでキーボードを閉じられる設定。消去ボタンで再フォーカス。明示的なAXラベルと操作ID |
| 検索の案内・結果なし | 大きな文字とキーボードで案内の末尾へ届かない可能性。人物/資料/ツールで結果なしの戻り方が弱い | 案内をスクロール可能にし、検索語の消去を標準ボタンで提供。人物・資料は結果件数も表示 |
| ツール検索 | 空の検索欄の後ろに全カタログが残っていた | 入力前は案内だけ、入力後は選択中の分類の結果だけを表示 |
| ツール・共通の分類選択 | segmentedの長いラベル、大きな文字での横スクロールが必要 | 通常は共通の文字タブ。アクセシビリティ文字サイズでは標準メニューPickerに切替。通常タブも外部の選択変更に表示位置を追従 |
| コネクタ | 接続済み/未対応以外に状態の表示がなく、未接続と区別しにくい | 実装済みサービスには「未接続」を表示。未対応を接続可能と見せない |
| ライブラリの選択中 | 通常の削除スワイプ・長押し操作、サンプル削除、共有記録やソースへの遷移が混在 | 選べるローカル記録と一括操作に集中。長押しは選択切替のみ。選択開始時は検索を終了し、消えたIDを選択集合から除去 |
| 一括操作・選択の読み上げ | 最大文字サイズで4列は窮屈。選択/未選択と操作対象件数を伝えにくい | 大きい文字では2列、各ボタンに選択件数、行に選択状態と切替のヒント |
| 一覧の読みやすさ | 大きい文字でも記録/プロジェクト/資料の識別名が2行で切られる | アクセシビリティ文字サイズではタイトル・プレビューを折り返して表示。記録のアイコンと選択印を上へ逃がして本文の幅を確保 |
| サンプルの案内 | iPhone 17eの最大文字で説明と削除ボタンが細い2列になり崩れる | 大きい文字は縦配置。削除の実ラベルを44pt以上とし、従来の確認を維持 |
| タスク編集・期限・出典 | 本文がonTapGestureと手動button trait。期限表示が横一列。消えた元会議の矢印が残る | 本文を標準Buttonへ変更。大きい文字では期限切れと日付を縦配置。元会議が存在する場合だけ導線を出し、会議名もAXラベルへ含める |
| 人物一覧 | メモが空白だけだと説明が空になる | 記録がない人の空メモには既存の案内を表示 |
| 会議・設定等の戻る | 独自の戻るボタンで標準のナビゲーションを置換している | 共通の戻ると会議詳細を標準へ戻す。会議名をバーにも表示し、ライブラリの会議遷移を標準pushへ統一 |
| Ask AI・録音・編集保護・設定・資料出力 | 既存の状態遷移/機密境界と前回までの修正を壊さない | 既存回帰検査を実施。新規サービス接続、録音エンジン、会社原本PDF等の拡張は行わない |

共通コンポーネントの変更は、それを使う会議詳細・プロジェクト内の分類・設定等にも反映される。全画面の全状態を視覚検証済みという意味ではない。未接続サービスは既知の未実装範囲であり、表示を隠して実装済みとは扱わない。
