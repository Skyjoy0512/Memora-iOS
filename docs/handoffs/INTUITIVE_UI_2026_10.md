# 操作を先に、説明を減らすUI — 2026-10-31

利用者の「全体的にもっと直感的に。細かい注意書きは不要」という指示による変更。
説明を短くするだけでなく、普段の操作を表に出し、細かい設定と管理を一段下へ整理した。

## 変更

| 領域 | 操作と表示 |
|---|---|
| 要約 | カードと全テンプレートの長い一覧を、AI・まとめ方・詳しさの標準フォームへ置換。形式は標準の選択リスト。用途/処理方法は詳細設定に格納。クラウドの実送信先と「送信して要約」は表示する |
| 要約の選択状態 | 形式リストから戻っても詳しさや用途を初期化しない。送信禁止の場合は理由と許可設定への直接ボタンを表示。確認用チェックボックスや永続的な送信許可は追加しない |
| 記録詳細 | 本文の上に履歴と再要約を配置。タブと重複する要約見出しを撤去。空の決定/未決/タスク/要点は非表示。既存の項目は引き続き閲覧・編集できる |
| 追加・編集 | メニューにタスク追加、要点/決定事項の編集、参加者編集を維持。要点編集は下書きをSQLiteに保持し、既存のcommitMeetingChangeで保存確認後に閉じる。元の項目が編集中に変わった場合は上書きしない |
| 未処理と処理中 | 次の操作を示す短いカード。毎回のAI利用の注意書きと、処理状況を重複して説明する文を撤去。処理の実時間・実イベントによる状態表示は維持 |
| 原文・Ask AIへの質問候補 | 常時表示の操作説明を撤去。標準の編集・表示切替・質問ボタンとアクセシビリティの操作名を維持。質問候補は下書きを作り、自動送信しない |
| 参考資料の追加 | リンク・ファイル・メモを先に選び、その入力だけを表示。選択を設定として保存。既存のメモ下書き、取り込み先の確認、失敗時の入力保持、標準ピッカーは維持 |
| YouTube字幕 | 貼り付けボタンと本文入力を先に表示し、「保存して次へ」で要約設定へ。文字数制限は超過時だけ表示。リンクのみから字幕を取得したとは表示しない |
| 参考資料の詳細 | 取得情報の説明より、字幕追加/要約を開く/Web本文の取得を先に表示。読み込み情報は詳細へ。取得済み/未取得・部分的な取得の状態は表示する |
| ライブラリ・プロジェクト | 表示語を記録・参考資料に統一。日付別の自分の記録を先に置き、チーム共有と参考資料を後に配置。状態フィルター中は対象外の参考資料を件数にも混ぜない。共有/参考資料だけある場合に空状態を重ねない。音声がない記録に架空の00:00を表示しない。作成メニューは短い動詞、空画面は次のボタンを優先 |
| ツール | スキル・要約テンプレート・連携の名前に整理。＋は今の分類に対応する追加操作だけを表示。接続可能なサービスと準備中のサービスを分ける。スキル/テンプレートの作成とMCP登録は維持 |
| AI設定・連携 | AIは標準Pickerで選択。状態と設定操作を先に表示し、説明の重複を撤去。詳細なモデル上限・参照権限・未接続の理由は詳細設定で確認可能。未提供サービスは準備中と表示 |

## そのまま維持した契約

サイドメニューと上部の作成操作、検索中の表示、Ask AIコンポーザーの位置と会話保持、Lucide、
SQLiteとファイルの保存先、原文・要約履歴、録音/STT、モデル選択/権限/予算/一回限りの送信指示、
外部操作の承認、バックグラウンド要約の実行・再送方針は変更していない。
RootTab/LibrarySection/ProjectWorkspaceTab/ToolsSectionの保存済み識別子は同じ。
Project.json、サービスの認証・バックエンド実装にも変更はない。
