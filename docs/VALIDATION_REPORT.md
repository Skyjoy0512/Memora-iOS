## 環境

- プラットフォーム: iOS 18 デプロイ対象 / iOS 27.0 SDK
- ビルド: Bitrig 内蔵シミュレータ（iPhone 17 Pro Max）
- シムの問題: 「does not support simulator state」が断続的に発生し、
  操作・録画による検証ができない期間がある。

## 未検証項目（実機/シミュレータで確認が必要）

- 主要4画面の表示とタブ切り替え（Liquid Glassの連続変形は操作動画で確認）。
- 録音→文字起こし失敗→再試行の一連。
- 破損データからの起動時アラート表示。
- 音声ファイル削除の失敗アラート。
- キーボード・最大文字サイズ・VoiceOver・Reduce Motion。

## 計画（フェーズ5で計測）

- 検索: 1,000件の検証データで入力から結果表示まで p95 300ms以内。
- 起動・検索・保存・画像表示・処理時間を変更前後で比較し、計測値と対応付ける。
- 本文・音声・キーを含まない計測に限定する。
