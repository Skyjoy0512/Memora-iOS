# 内容に沿う1枚サマリー

2026-10-24。対象は記録詳細の `summary.poster.inline` と「タスクを追加」。

## 変更

- 固定の「要旨／決定事項／次のアクション／未解決事項」枠を廃止。保存済みMarkdownの見出し・親見出し・段落・箇条書き・表の列名を、原文の順序で配置する。空の見出しは枠を作らない。
- 入れ子の理由・条件は親項目に添え、分岐マークとインデントで表示。表は列名と値を組にして表示する。入れ子だけから因果関係を推測しない。
- 追加のAI呼び出し・外部送信・料金は発生しない。保存本文・文字起こし・要約履歴は変更しない。
- PNGは幅1,440px、高さは内容に合わせて最大2,400px。ネイティブのレイアウト寸法を測ってから画像を割り当てる。収まらない場合は項目グループ単位で減らし、注記を表示する。安全上、最大8セクション・各3グループ・各6行、1行320文字（複数行のグループは90文字）の上限も設ける。長文の全文表示・編集・共有確認は従来どおり。
- 「タスクを追加」は既存の `MemoraButtonStyle(.secondary)` を再利用。控えめなカプセル、最小44pt、Dynamic Type・Reduce Motion対応。新規作成／編集の既存シートとSQLite保存経路は変えない。
- 作成／編集欄に明示的なアクセシビリティラベルを追加。入力後も「すること／タイトル」「メモ・完了条件」を識別できるようにする（見た目は変更しない）。
- snapshotによる編集・削除・プライバシー変更・workspace変更時の無効化と、共有用一時ファイルの削除は維持。
