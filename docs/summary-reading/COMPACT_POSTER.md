# サマリー画像の余白・重複項目の整理

2026-10-24。利用者の指定に合わせた局所的なUI変更。

- 画像の720 × 1200pt固定キャンバス、決定／アクション欄の300pt固定高、末尾を押し下げるSpacerを外し、内容に合う高さへ変更。幅・文字サイズ・抜粋上限・未抽出の説明・モノトーンは維持した。空欄を埋めるために内容を生成しない。
- PNGの幅は引き続き1440px。高さは内容次第であり、画像シートには実際のピクセル寸法を表示する。常時表示・拡大・全文・共有確認・一時ファイルの削除・アクセス変更時の失効は維持する。
- サマリーの「要約の項目と原文」という重複する折りたたみ項目だけを非表示にした。サマリー本文のインライン編集、テンプレートの表示、機密区分の注意、要約履歴、文字起こしタブ、元の音声・発言・引用データは削除していない。保存や生成のコード・SQLite形式は変更していない。
- native-app-designとHIGの[レイアウト指針](https://developer.apple.com/design/human-interface-guidelines/layout)を参照し、内容の量に合わせる配置と既存の階層を優先した。Liquid Glass・ナビゲーション・アニメーションは作り替えていない。

## 検査の範囲

既存の要約ホスト検査を再実行。E2Eは通常のPNGと空欄の多いPNGを実際に書き出し、幅・高さ・署名・共有終了後の削除を検査する。元の発言本文と要約履歴の保持もDBから照合する。

重複項目の非表示は、対象のカタログテンプレート、実際の要約バージョン、空でない本文セクションを持つ明示的なフィクスチャで検査する。先にテンプレート名と要約履歴が表示されていることを確認し、単に対象データが無くて項目が出ないだけの検査にしない。

テストは専用Simulatorの検証用データを使い、利用者のプレビューのDBは変更しない。生成モデル・実音声・実アカウント・外部送信は使っていない。実機のVoiceOver／日本語IME／電池・描画速度はこの変更では未検証。PNGの高さはレイアウトの寸法であり、処理速度の改善率ではない。
