# 要約・文字起こしの保存失敗と復旧

## 修正範囲

文字起こしの編集は以前、モデルを先に更新して保存をバックグラウンドへ渡し、編集UIには常に成功を返していた。セグメントごとの下書きキーもなく、保存失敗後の入力を復元できなかった。要約・ノート・話者名の共通保存経路も、保存前の状態を画面へ公開していた。

- 文字起こしの確定は保存結果を返す。セグメントUUIDごとに既存のSQLite `DraftStore` を利用し、本文と下書きを取り違えない。
- 共通の会議編集は候補を作り、保存成功後だけモデルと検索キャッシュを更新する。失敗時に未保存の内容を確定済みとして表示しない。対象は文字起こし本文・要約・ノート・話者名で、録音・要約生成の保存やその他のCRUDを一括変更するものではない。
- JSON化は既存の `RecordStore.encoded` を使いバックグラウンドで行う。その後に元の記録集合・ワークスペース世代・個人領域・復元／保護／キャンセル状態を再確認する。並行した別編集や削除があれば候補を破棄し、他の変更を巻き戻さない。
- 再検証から既存の順序付きSQLiteトランザクションとモデル反映まではActorの中断を挟まない。JSON化はUI Actorから外すが、最終のSQLiteコミットは順序を保つ同期処理であり、巨大データでの待ち時間がゼロになる保証ではない。
- 既存のインライン編集UIは、下書きの保存自体が失敗しても同じView内の未保存入力を保持する。再編集時は最新の保持内容を優先し、保存成功後だけ破棄する。ディスクへ一度も書けない場合のアプリ終了後の復元は保証しない。
- 再編集を始める際は古い未完了の保存Taskを取り消し、以前のJSON化が完了しても新しい編集を上書きしない。すでにコミット済みの操作を取り消したり、別セッションの下書きを削除したりするものではない。
- UI、Liquid Glass、録音のセッション・音声ファイル・話者／時刻・既存データ構造は変更しない。既存の復元表示と保存エラー通知を再利用する。

## 検証方法

`MeetingEditChecks.swift` は本番の `MemoraModel+Meetings` をそのままコンパイルし、隔離SQLiteのINSERTをABORTさせ、4種の編集の失敗・再試行・再読込・キャッシュを検査する。モデル容器・未使用のMeetingフィールド・待機制御付きのエンコード口はホスト用ハーネスであり、iOSの実モデル全体の検証ではない。文字起こしセグメントとSQLiteは本番コードを利用する。JSON化を明示的に待機させた7つのレース（別編集・チーム・世代変更・復元・保護・キャンセル・削除）でも古い候補が保存／反映されないことを検査する。

`summary-recovery.e2e.ts` は既存のE2E専用Simulatorを再インストールし、UI作成のUUIDメモでSQLiteを識別した後に明示的な検証会議を投入する。

- 会議文書の保存だけをABORT：保存済み原文が残り、下書きは再起動後に復元できること、再試行で保存と下書き削除ができることを確認する。
- 会議文書と該当セグメントの下書き保存を両方ABORT：同じView内の再編集で入力を保持し、復旧後に保存できることを確認する。
- PNGの書き出し失敗：識別済みのテスト用コンテナのtmpディレクトリだけを一時的に書き込み不可とし、実際のファイルI/Oエラーを起こす。シンボリックリンクやコンテナ外のパスは拒否し、元のアクセスモードをfinallyで戻す。ユーザーのプレビュー・実機・元データの権限は変更しない。実容量を使い切る試験や権限の迂回は行わない。
- PNGの再試行で本物のPNGと共有シートを確認し、共有キャンセルで一時コピーが消え、プレビューが残ることを確認する。共有先へ送信・保存はしない。

共通のテスト会議作成は `summary-fixture-helpers.ts` に集約し、通常の要約画像・原文表示・再編集・最大Dynamic Typeの回帰シナリオでも同じ準備経路を使う。サンプルの実行結果をアプリに組み込む変更ではない。

環境：Apple Silicon / macOS 27.0.1、Swift 6.4、iOS 27.1 SDK、iOS 26 deployment target。UIはE2E専用のiPhone 18 Pro Max Simulatorで実行した。

- 最終追補を含むDebugの `bitrig preview -platform iOS` 成功、利用者プレビューを更新。ログ `2026-10-24T13-25-42-62fd76ec.log`。
- 同じコードのRelease `bitrig build -destination 'generic/platform=iOS Simulator' -configuration Release` 成功。ログ `2026-10-24T13-27-11-5c2d47dd.log`。既存の非推奨API等の警告は残る。実機向けの署名・実行確認ではない。
- ホスト回帰：next-generation / design-refresh / background-summary / composer-layout / optimization の5スイートすべて成功。新しい会議編集・7種の競合検査も含む。証跡は `/Volumes/WorkspaceSSD/Development/Temp/memora-summary-recovery-async-quality-20261024/summary.json`。
- UI回帰：`native-header` 4件、`summary-reading` 1件、`summary-recovery` 2件、計7件すべて成功、失敗・スキップ0。証跡は `.e2e/regression/summary-recovery-final-20261024/report.json`。保存の非同期化までを含み、後続の再編集時Taskキャンセル追補より前の実行。
