# 公開までのロードマップ

| 優先度 | 公開条件・価値 | トラッカー |
| --- | --- | --- |
| P0 | データを失わず取り込み・保存・復元できる。資格情報とアクセス範囲を守る | SEC-01、SEC-02、STORE-01、STORE-02、CAP-01、QA-01 |
| P0 | 蓄積した記録を横断し、根拠・人物・時系列を保持して返す | MEMORY-01、MEMORY-02、OCR-01 |
| P1 | 音声を既存パイプラインで文字起こし・適応型要約し、担当者を確認できる | AUDIO-01、AGENT-01 |
| P1 | 主要画面の一貫性と読みやすさ、配布資料の視覚品質、オンライン会議の捕捉 | UX-01、PPTX-01、BOT-01 |
| P2 | フィードバックと測定に基づく意味検索、同期、追加インテグレーション | 実データと品質・費用の根拠が揃えば評価 |
| 保留 | Live 会話、通話、商用可否未確認の ChatGPT OAuth | 開発用経路を維持。一般公開は別判断 |
| 外部依存 | 物理端末、BYOK 有効アカウント、権限を得た会議、配布・クラウド | 実サービス許可と実機のテスト枠が必要 |

進行中の作業は [実行状態](EXECUTION_STATE.md) と [バックログ](TASK_BACKLOG.md) に記録。過去の技術候補は [既存改善バックログ](../IMPROVEMENT_BACKLOG.md) を参照。
