# Memora の変更履歴

## 公開準備

- API キーの更新に失敗した場合も、端末に保存済みの資格情報を保持する。
- 公開版は設定済みの API キーでクラウド AI を案内する。以前の ChatGPT 連携は端末から解除できる。
- 同じテキストや共有画像を同時に取り込んだ場合でも、原本を一つだけ保存する。
- 大量の記録を保存する際に、端末が一時的に保持するデータのコピーを一つ減らす。
- カレンダーから録音を開始するときは選択シートが閉じた後に進み、選んだ保存先を再確認する。
- 以前のデータを読み戻す途中に失敗しても、新しく保存した記録や既に退避した原本を守る。
- バックアップから戻した録音と写真にも、端末のファイル保護を適用する。
- 写真内の文字から記録を検索できる。画像の差し替えや削除で、古い文字が検索に戻るのを防ぐ。
- 未完了タスクが多いときも、Ask AI が回答に使った記録と発言を出典として示せる。
- 0%を含む比例円のスライドも PowerPoint に書き出せる。
- 過去の回答をクラウドで参照するときは、元のリクエストで取得した根拠と現在の許可が確認できる場合に限る。
- プロジェクトチャットの出典に記録日が表示され、Ask AI は記録日と録音内の発言位置を区別できる。別のプロジェクトに移動された記録は、以前の回答から開けなくなる。
- 端末内のプロジェクトチャットは写真の文字も根拠にできる。出典から元画像を確認でき、写真を消すと以前の出典からも開かなくなる。
- 端末内の Ask AI でも、保存した写真の文字を探し、番号付きの出典から元画像を開ける。
- 文字を最大サイズにしても、記録詳細と文字起こしの操作は入力欄に重ならず、キーボードを出したまま検索できる。
- 「記録日」を指定して、プロジェクトチャットの検索対象をその日の記録に絞れる。
- MCP の認証を取り消してやり直したとき、前の認証の応答が届いても新しい接続に影響しなくなった。
- タスク画面のタイトルが「未完了／完了」の切替に重ならず、どちらも押して切り替えられる。
- 未接続のコネクタでも「Ask AIで使う」を切り替えられ、有効にしたあとで元に戻せる。
- マーケットプレイスの一覧で行をタップすると、スキルやコネクタの詳細が開く。
