# Memora の公開準備状況

対象は Bitrig の iOS SwiftUI 版。2026-11-25 の開始点は `cd0d82da`。GitHub `main` は `45c93543` で、開始点の祖先。Bitrig `origin/main` は開始点と一致。実装欄は現行の経路を、検証欄は確認できた証拠を示す。

| 機能 | ユーザーができること | 実装状況 | 検証状況 | 残課題 |
| --- | --- | --- | --- | --- |
| ライブラリ・ジャーナル・Ask AI | 一覧、日付、会話を切り替える | 実装済み | 開始点 iPhone 18 Pro 目視と UI E2E 4 件 | 全主要画面の実機・文字拡大・ダーク巡回 |
| 保存・ゴミ箱・バックアップ | 端末に記録、復元可能なバックアップを作成 | 実装済み。記録コレクションは全件 BLOB | SQLite・バックアップには既存ホスト契約あり。現行結果は TEST_STATUS | 大規模増分保存、旧版非破壊移行、実機移行・容量不足 |
| プロジェクト・人物・タスク | 記録、資料、参考資料、チャット、画像を整理。人物・タスクを参照 | 実装済み。チーム共有は読取スナップショット | 11月の5セクション実装と関連ホスト・UI 契約 | 実際の CloudKit アカウント間共有、権限変更・競合 |
| 録音・外部レコーダー | 内蔵マイク録音・対応機器から取込 | 実装済み | 端末内処理と復旧にホスト検証。物理機の状況は別途 | 画面ロック、Bluetooth、長時間、強制終了、温度・電池 |
| 音声・動画・URL・共有取込 | 端末内ファイルや対応 URL を記録・資料に追加 | 実装済み。サービス応答と抽出範囲に依存 | 実 SQLite とファイルを使う取込回帰を実施 | 写真 Picker の実転送、実 Web/YouTube、Office 形式別検証 |
| 画像・OCR | プロジェクト画像の文字を端末で検索 | 部分実装 | Vision は実機経路。更新競合は別途検証 | ライブラリ・Ask AI・資料の原画像付き引用、閲覧と送信の境界 |
| 文字起こし・話者・要約 | タイムスタンプ付き文字起こしと適応型要約。担当者を確認 | 実装済み。一部エンジンは端末・構成に依存 | 本番 Core ML の合成入力・元時間対応をホストで確認。精度比較は未実施 | 日本語・混在・雑音の精度、長時間、実 BYOK 互換 |
| 長期記憶・横断検索 | 明示した記憶、過去の関連会話、記録・参考資料を探す | 部分実装。既存の FTS5、記録ランカー、資料抽出 | 合成 fixture で範囲・失効を検査。横断質問の総合精度は未計測 | 統合された根拠の選択・時系列・削除・評価コーパス |
| Ask AI・外部ツール | 回答の根拠を辿る、承認してタスク等を操作 | 部分実装。実連携は設定に依存 | 実 SQLite と fixture を使うシナリオが存在 | 実アカウント、通信中断、全再検証と復元範囲 |
| 資料生成 | PDF、PowerPoint、テキストを出力 | 実装済み。企業テンプレートは条件付き | ZIP/XML、ページ組版の既存検証 | 65 スキルの照合、Office 実描画、出典品質、モデル間比較 |
| OAuth・BYOK | 設定した API キーでクラウド AI を利用 | BYOK 実装済み。ChatGPT OAuth は開発用、公開版の連携は保留 | 資格情報の失敗分岐・ビルドフラグをホストで検証 | ロック実機、公開承認と対象の正式な推論 API 経路 |
| オンライン会議 Bot | 会議を指示し、許可のもとで音声取得 | 未実装。機能フラグは無効 | 公式仕様・運用試算を調査。実会議未実施 | 参加方式・許可・同意と分離された実環境 |
| チーム、クラウド AI、購入、市場 | 保存した設定と利用可否を確認 | チーム共同編集・アカウント・決済・Memora Intelligence は未接続。市場は設定と配備が必要 | 静的・fixture の動作を確認できる。実運用未検証 | 本番構成・権限・費用・配備と実アカウント |
| 通話・Live 音声対話 | 対象機能は開発時に確認可能 | 意図的に保留 | 開発側の既存チェックあり | 公開判断および端末・モデル・録音許可の検証 |
