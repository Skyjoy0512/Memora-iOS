# Ask AI — チャットからのWeb検索

通常のAsk AI／録音／プロジェクトのAIスコープを維持し、明示したWeb調査だけを別の根拠として扱う。APIキーを設定して利用する実装を追加済み。実サービスを使うE2E確認は未実施。

## 接続と実行

設定 › AI整理 › Web検索にBrave Search APIキーを登録する。KeychainStoreへ保存し、UserDefaults・バックアップ・ログにはキーを含めない。APIキー未設定時には検索せず、チャットで未接続と案内する。

「箱根の観光情報を検索して」「iPhoneの最新価格を調べて」などの依頼を通常のAsk AIから送ると、Web検索・回答・出典を同じ会話に表示する。Web検索／Deep Researchの選択画面は主な利用導線から外した。マイク／送信ボタン左のアイコンは「Webで検索」のToggleとして次の1回の送信に作用し、受付後にオフへ戻る。選択中は入力ヒントも変え、キーボードや下書きを消さない。上部の検索は従来の記録検索。録音／プロジェクト単位の入力欄のスコープは維持する。

AIWebSearchIntentは明示的な検索／調査依頼を判定する。録音、会議、資料、人物、タスク、ジャーナル等の依頼は、明示的なWeb指定／Toggleがない限り既存の内部検索へ送る。否定形はWebへ送らない。話題のない「検索して」には何を検索するか聞く。「もっと詳しく」は直前のこの経路のWeb検索テーマだけを補って再検索する。過去の回答本文、録音、メモリ、メール、添付を検索語へ自動追加しない。通常の明示検索は検索API1回・AI回答最大1回で、自動再送しない。検索料金とAI料金は設定画面で案内する。

検索だけ成功してAIモデルが利用できない場合は、取得件数と実際の失敗理由を表示し、出典の閲覧とプロジェクト保存を利用可能にする。検索未実施なのに結果や回答を生成しない。元の手動調査ビューと既存の検索モードrawValueは互換性のため残すが、通常利用では選択を求めない。

既存のエージェントにもsearch_web／deep_researchを提供する。エージェントが生成した検索語は、問い合わせ上限を示した承認後だけ実行する。常駐エージェントと分担調査の子担当には提供しない。この経路は1つの回答につきWeb調査は1回、最大3検索。辞退・失敗・停止後の自動再送はしない。通常の明示検索はこのツール選択・承認カードを経由しない。

Web検索は固定のBrave Web Searchエンドポイントで最大8件の検索抜粋を取得する。Deep Researchは指定した1〜3の検索語でBrave LLM Context APIの抽出本文を取得し、最大16のURLへ統合する。任意のページURLをアプリから自動取得する経路は追加しない。全ページの全文読了・網羅的調査とは区別する。

## ソースと回答

問い合わせ開始／完了、取得日時、検索抜粋／抽出本文を保持する。正規化した公開HTTPS URLだけを受け入れ、重複URLは統合する。応答2MB、各ソース本文8,000文字、合計16ソース。送信先は固定ホストのみ、リダイレクト・Cookie・既存認証情報を使わない。検索語は600文字・75語以内。

AI要約には選択中の既存モデルを使用し、1回だけ実行する。検索語・取得済みの本文だけを渡し、個人メモリ・メール・録音等を自動で混ぜない。モデルの文脈予算に合わせてソース本文を制限する。取得ソースとAIへ実際に渡したソースと回答が引用したソースを区別する。引用番号は実際に渡した【Webn】だけを解決する。外部本文の命令は実行しない。エージェントの場合も既存の権限管理・操作承認を維持する。

## 保存

調査履歴はSQLiteのmemora.webResearch.v1へ保存し、アプリ再起動で保持する。停止や要約失敗でも取得済みソースを残す。旧バックアップと互換性のあるoptionalフィールドとしてバックアップに含める。APIキーは含めない。

通常の質問履歴にoptionalのwebResearchReportIDを保存し、履歴から出典・プロジェクト保存・続きの検索を開ける。以前の手動／エージェント調査も質問履歴画面へ表示し、既存データへの導線を残す。isChatSearchもoptionalで、旧JSONを読み込める。Web回答は検証できる【Webn】だけをリンク化し、架空の番号は除去する。検索時に過去の会話の本文は送信しないため、履歴を開いただけで再検索や課金はしない。

既存または新規のプロジェクトへ、取得本文を持つWebソースと調査レポートのメモを保存する。同じURLの既存ソースは再利用し、本文が未取得のときだけ補う。元の本文は上書きしない。新しいファイルを用意してからソースとレポート所属をSQLiteでまとめて保存する。保存中の別編集を検知した場合は中止し、作成したファイルを片付ける。外部AIへの再送許可は自動付与しない。調査履歴だけの削除は、プロジェクトへ保存したソースを削除しない。
