## 操作と表示

- ライブラリ、プロジェクト、ジャーナルの検索案内と空結果を共通化。拡大時は検索欄内の消去ボタンを使い、案内とキーボードが競合する重複操作を省く。
- Ask AIと検索のプレースホルダーにライト・ダーク対応の文字色を設定。添付に紙クリップを使い、録音や作成の＋と見分けられるようにした。
- サイドメニューの閉じる操作をアクセシビリティツリーに追加。閉じたメニューを画面外に移し、背後の画面は開いている間だけ読み上げ対象から外す。
- 既存の余白を使って一覧・本文・操作カードの間隔を統一。警告を閉じるボタンは日本語の「閉じる」にそろえた。
- Ask AIの生成UIは、キーボードのフォーカス輪郭と可視領域に収まるダイアログを優先。グラフの負値はゼロより手前に描き、ゼロの棒は描かない。

iOS 27.2のBitrigプレビューでビルド成功。最大文字サイズのダーク表示で検索語の入力・消去・キャンセル、録音メニューの4項目を確認した。「視差効果を減らす」が有効な場合のサイドメニューの開閉とアクセシビリティツリーも確認した。プレビューは通常のライト表示へ戻した。生成UIのDOM・契約テストは13件通過。

iPhoneのE2Eは異なる5ケースが通過。主要4画面と設定への遷移、マーケットプレイスの詳細・追加・検索、録音メニューと下書き、検索語の消去とフォーカス、ライブラリとプロジェクトの検索を確認した。検索テストは同名の入力欄と見出しを区別できるように修正し、同じアプリビルドで再実行した。

実際のVoiceOver読み上げ、実機での録音と同期、外部サービスの接続は未検証。

## 2026-11-21の追加点検

- Ask AIの検索結果が空のときも「検索語をMemoraに聞く」と絞り込み操作を使える。空結果の案内はリストの行として表示する。アクセシビリティ文字サイズでは絞り込み項目を一つのメニューにまとめる。検索中の再描画で計測ログを更新していた処理を、診断画面で明示的に計測するときに移した。
- 記録のサマリー・文字起こし・ノートは、長文をスクロールした先からも切り替えられ、切り替え時は先頭に戻る。拡大設定では参加者名をラベルの下に表示し、長い名前を折り返せる幅を確保する。
- 生成回答のフォームでは、入力欄と選択欄を表示ラベルに対応させる。繰り返し項目が同じ名前を使っても、ラベルから別の項目が切り替わらない。入力の保存先は既存のバインディングを使う。

同じ設定での再走査は、エラー23件、警告145件。書き出し画像や同梱コードの検出も含む。iOS 27.2のプレビュービルド成功、生成回答のDOM・契約テストは14件通過。

追加のiPhone E2Eは2件通過。Ask AI検索で複数文字を入力し、空結果と質問操作が別々に表示されることを確認した。記録では拡大表示と表の横スクロール、要約の末尾から固定されたタブを押して文字起こしを開けることを確認した。プレビューでは最大文字サイズの絞り込みメニューと、サンプルの文字起こし末尾からノート先頭への切り替えも確認した。「1枚サマリー」は現行ビルドの機能フラグで非表示のため、画像書き出し経路は今回の検証対象外。
