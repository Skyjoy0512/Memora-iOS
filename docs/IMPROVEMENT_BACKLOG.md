# Memora — 改善バックログ

レビュー指示書の項目ごとの状態。状態: 未着手 / 実装済み / 検証済み / 保留。
「実装済み」はコードに入ったこと、「検証済み」は実機・シミュレータで確認済みを指す。

## B. 録音・再生・インポート

| ID | 状態 |
| --- | --- |
| B01 | 実装済み | 準備中/保存中の明示状態と再入防止。終了は保存中表示で無効化 |
| B02 | 一部 実装済み | 録音中は音声入力を理由付きで拒否。セッション所有者の一本化は残 |
| B03 | 実装済み | 割り込み・経路変更・オーディオリセットを検知し、録音を理由付きで一時停止（利用者が再開）。リセット時はここまでを保存 |
| B04 | 実装済み | 録音下書きを永続化し、起動時に中断を検出して「復旧した録音」として回収（音声が無ければメモ）。自動再録音はしない |
| B05 | 実装済み | `AudioPlayerService`（AVAudioEngine＋AVAudioFile）で再生・一時停止・シーク・15秒送り戻し・速度変更。詳細の再生バー。録音中は再生しない |
| B06 | 実装済み | 発言の時刻をタップするとその位置から再生し、再生中の発言を強調。時刻情報が無い文字起こしでは時刻を押せない見た目にする |
| B07 | 実装済み | Live Activityは実経過時間を表示し、一時停止中は数値を凍結して「一時停止中」と表示。起動時に残留Activityを終了（録音は自動再開しない） |
| B08 | 実装済み | 録音シートの文字起こしタブに「録音を終えると文字起こしします」を表示（リアルタイム文字起こしは後続） |
| B09 | 実装済み | 取り込みのコピー・検査をメインアクター外で実行。再生可能性と実長さを検証し、実測できない進捗は不定表示、失敗時は一時ファイルを削除 |
| B10 | 実装済み | クラウド送信をファイルベース（全体をメモリに載せない）に変更。拡張子からMIMEを決定し、上限（OpenAI 25MB／Deepgram 2GB、公式仕様）を送信前に検査して説明 |
| B11 | 実装済み | 録音中の帯を全主要タブ（ジャーナル／ファイル／Ask AI／タスク）に表示し、タップで録音画面へ戻れる。タブ切替のアニメーションは変更なし |
| B12 | 実装済み | 再生中はコントロールセンター／ロック画面に記録の実際の名前と経過・長さを表示し、再生・一時停止・シークで操作できる。停止時は表示と操作を消す（録音側の表示はB07） |

## 保留の理由と解除条件

- **A01（デモと実データの分離）**: 独立ストア（A07）と同時に行うのが安全。
  解除条件: ローカルストア導入時にデモを別領域へ移す。
- **A06（復旧・書き出し）**: バックアップ基盤（フェーズ2）が必要。
  解除条件: バージョン付き書き出しパッケージの実装。
- **E01（safe areaのルート整理）**: 全主要画面の確認が必要で、シミュレータの
  状態APIが復帰してから検証する。解除条件: 実機/シミュレータでの確認。
