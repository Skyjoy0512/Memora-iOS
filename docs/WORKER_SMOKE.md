# ワーカー運用メモ（スモーク）

この1ファイルだけを変更対象とした短い運用メモ。UI・コピー・レイアウト・iOS 26 Liquid Glass、
タブ、依存関係、署名、`Project.json`、秘密情報、エージェント設定、git状態には触れない。

## 役割と流れ

1. **設計・タスク分割（Codex）** — Codexが作業範囲を決め、許可ファイルを限定した1つ以上のタスクへ分割する。
2. **実装（OpenCode Go DeepSeek）** — 隔離コピー内で、許可されたファイルだけを実装する。範囲外の変更は行わない。
3. **レビュー（Codex）** — 完成した差分全体をCodexがレビューする。
4. **検証（runner）** — runnerがモーション／ローディングテストとiOS Simulatorビルドを実行する。
5. **修復** — 初回試行のあとに続けられる修復は最大2回まで。

## 境界

- 実機確認と視覚確認は別工程であり、この流れに含めない。
- この実行自体はまだ合格していない。テストとビルドの実行はrunnerが行い、結果はそこで判定する。
